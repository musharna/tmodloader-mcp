# Lessons

- 2026-11-07: a single-slot safety copy (`auto-before-restore`) was re-taken on every restore, so the retry of a failed restore, or a second restore, saved a half-restored or already-saved state over the only original. Class: a backup taken unconditionally before a retryable operation. Caught now by `tests/test_saves.py` (retry after an injected second-copy OSError; restore A then B), which fail on the old code; not lintable, so no hook.
- 2026-11-10: the restore latch kept the old undo after a failed restore because the RECORD said the save was half-restored, without reading the save; play in between was overwritten with no copy. Class: a safety decision taken from a state record when the bytes it describes can change after it was written. Caught now by `tests/test_saves.py` (play after an injected failed restore; restoring the undo over a played save), which fail on the old code; not lintable, so no hook.
- 2026-11-10: `save_snapshot`/`save_restore` copied the configured world while `launch(world=...)` drove another, so a restore "succeeded" without touching the world the run changed. Class: an argument that overrides a setting in one tool and is never seen by the tools that act on the same thing later. Caught now by `tests/test_server_surface.py::test_the_save_verbs_follow_the_world_launch_loaded` and the world tests in `tests/test_saves.py` (mutants killed with `mutate-run`); not lintable, so no hook.
- 2026-11-10: the reserved snapshot label was compared case-sensitively on a save directory that lives on NTFS, and the restore record's own file name was a legal label. Class: a name check that does not use the comparison rule of the filesystem the name lands on. Caught now by `tests/test_saves.py` (reserved names in any casing; restoring the undo by another casing), which fail on the old code; not lintable, so no hook.
